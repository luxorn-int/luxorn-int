## Projects 

  ### **M-Engine:** is private now (WIP)

*   **Description:** 
  The M-Engine implements systems for a three-dimensional or two-dimensional world editor. Its main feature is a system of plug-ins at the    kernel level - the program can dynamically load and restart some of its modules: AudioModule(OpenAL), graphicalModule(OpenGL), PhysicalModule(CUDA in the future). Also important information will be that I used a combination of **Object-Oriented Programming** and **Data-Oriented Design** to improve performance.
*   **interesting facts:** The project is also gradually introducing a pair of NDK + JNI technologies for future porting to ARM64 android devices.
